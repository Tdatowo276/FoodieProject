# Ảnh banner trang chủ

Thả ảnh banner vào thư mục này với tên:

- `banner-1.jpg`
- `banner-2.jpg`
- `banner-3.jpg`

Kích thước khuyên dùng **1920 x 640 px** (tỉ lệ 3:1), dung lượng dưới 400KB.
Đặt chữ / giá ở vùng giữa ảnh vì trên điện thoại hai bên ảnh bị cắt bớt.

Muốn đổi tên file, thêm hoặc bớt banner: sửa `src/config/banners.js`.
Chưa có ảnh thì banner tự hiện nền đỏ kèm tiêu đề trong file cấu hình.
